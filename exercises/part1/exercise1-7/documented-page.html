MDI IT Class Study Guide

A simple study guide for Year 2, Semester 1 IT students at the Management Development Institute (MDI), The Gambia.

Use this guide to organize your studies, prepare for lectures, and revise your courses throughout the week.

2. How to Study Each Course

Networking I

Study how computers connect and communicate with each other. Review networking devices, IP addresses, network types, and communication protocols.

  • Review your lecture notes after class.
  • Practise drawing simple network diagrams.
  • Learn important networking terms and their meanings.

Operating Systems

Learn how an operating system manages computer hardware, software, files, memory, and running programs.

  • Understand the functions of an operating system.
  • Compare operating systems such as Windows and Linux.
  • Practise explaining concepts in your own words.

Web I & Database I

Practise building web pages with HTML and understanding how databases store and organize information.

  • Write and test HTML code regularly.
  • Practise creating headings, paragraphs, and lists.
  • Study tables, primary keys, foreign keys, and relationships.
  • Practise writing simple SQL queries.

Java I

Focus on the basic rules of Java programming and learn how to solve problems step by step.

  • Practise variables, data types, and operators.
  • Write simple programs using if statements and loops.
  • Practise writing and running Java programs.
  • Read error messages carefully and correct your code.

3. My Weekly Study Plan

Use the days without scheduled classes to prepare for upcoming lectures, complete assignments, and revise difficult topics. Adjust the plan when your lecturers give you new tasks.

  • Monday: Revise Networking I and Operating Systems. Prepare questions for Tuesday's lectures.
  • Tuesday: Attend Networking I and Operating Systems. Review both subjects after class and write down key points.
  • Wednesday: Practise HTML and SQL for Web I & Database I. Complete any outstanding assignments.
  • Thursday: Practise Java programs and revise important programming concepts before Friday's classes.
  • Friday: Attend Web I & Database I. Review the practical work and note anything you do not understand.
  • Saturday: Attend Java I. Review the lesson and practise writing a short Java program.
  • Sunday: Revise all four courses, organize your notes, and prepare for the coming week.

4. Tips for Studying Effectively

Good study habits help you understand your courses, remember important information, and prepare for examinations.

  1. Attend lectures on time and bring the materials you need.
  2. Review your notes on the same day as each lecture.
  3. Spend more time practising programming and database exercises.
  4. Break difficult topics into small, manageable parts.
  5. Ask your lecturers or classmates when you do not understand something.
  6. Take short breaks during long study sessions.
  7. Start assignments early instead of waiting until the deadline.
  8. Test yourself with practice questions before examinations.
